# Caminho de Python 🐍

Este repositório contém uma coleção de todos os projetos e scripts em Python que criei ao longo do meu aprendizado. Ele serve como um portfólio do meu progresso e evolução na linguagem Python.

## 📚 O que eu aprendi

Através destas atividades, consolidei diversos conceitos fundamentais e avançados de programação em Python, incluindo:

### 1. Lógica de Programação e Fundamentos
- **Estruturas de Controle:** Uso de condições (`if`, `elif`, `else`) e manipulação de laços de repetição (`for`, `while`) para cálculos e contagens iterativas (`for.py`, `cParImpar.py`).
- **Operadores Matemáticos e Tratamento em Lote:** Criação de calculadoras e operações numéricas constantes (`AtvCalculadora.py`, `soma.py`, `tabuada.py`).

### 2. Estruturas de Dados
- **Listas e Matrizes:** Manipulação de listas, adição/remoção de itens dinamicamente e criação de matrizes uni e bidimensionais (`listafun.py`, `matriz.py`, `numList.py`).
- **Dicionários:** Armazenamento de dados em pares chave-valor para busca eficiente, inserção e deleção em tempo real (`dicionario.py`, `AtvDic.py`, `dicioAddExcluir.py`).

### 3. Orientação a Objetos (POO)
- **Classes e Objetos (OOP):** Modelagem e abstração do mundo real usando classes, lidando com métodos e atributos sob demanda (`restaurant.py`, `alien.py`, `admin.py`).
- **Modularização de Funções:** Estruturação avançada e divisão de blocos funcionais e arquivos do sistema evitando repetição (`function.py`).

### 4. Manipulação de Arquivos e Strings
- **I/O e Tratamento de Encodings:** Leitura e escrita sistêmica de arquivos de texto, e correção de problemas ou corrupção de enconding (`arquivoUTF-8.py`, `arquivoChardet.py`).
  
- **Formatação de Dados:** Apresentação amigável e conversões de interface de dados no console para maior legibilidade (`AtvFormat.py`).
